COMO LIGAR (5 minutos, uma vez so)
=====================================================================
1) Token do projeto no Railway
   Railway -> projeto honest-gentleness -> Settings -> Tokens (ou "Project tokens")
   -> New token. Use token de PROJETO. Token de conta/team costuma falhar com
   "Project Token not found" ou 401.
   >>> NAO cole esse token no chat, nem em arquivo, nem em print. <<<

2) Salvar o token no GitHub (como secret, nao como variable)
   github.com/emausplataforma/Emaus -> Settings -> Secrets and variables -> Actions
   -> New repository secret
   Nome:  RAILWAY_TOKEN
   Valor: o token do passo 1

3) Conferir que Actions podem rodar
   Settings -> Actions -> General -> Workflow permissions: deixe o padrao
   (Read repository contents). Nada de "Allow all actions" e necessario.

4) Subir os 4 arquivos (Add file -> Upload files -> Commit directly to main)
   O push ja dispara sozinho.

5) Onde olhar o resultado
   aba Actions -> "Publicar API no Railway". O ultimo passo imprime
   health=200 e o JSON {"ok":true,"service":"emaus-api",...}.
