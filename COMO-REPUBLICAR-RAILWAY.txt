PLANO B - publicar sem depender do GitHub (CLI do Railway)
-----------------------------------------------------------
Use se o Plano A travar. Roda no SEU computador, no terminal. Nada de
senha vai para o chat: o login e feito pelo proprio navegador do CLI.

  npm install -g @railway/cli
  railway login
  railway link          # escolha honest-gentleness / production / Emaus

Depois, dentro da pasta que contem server.js, package.json,
schema.sql e billing-mercadopago.js (os arquivos deste ZIP):

  railway up

O CLI sobe o codigo e dispara o build. Variveis privadas do Railway
(DATABASE_URL, JWT_SECRET, PASTOR_PASSWORD...) nao sao tocadas.

Atencao: o proximo deploy via GitHub pode sobrescrever esse build.
Assim que o Plano A voltar a funcionar, prefira ele.
